# 🔢 Universal Number Base Converter

A simple number base conversion project that converts a number from **any base (2 to 36)** into four commonly used number systems:

- Decimal (Base 10)
- Binary (Base 2)
- Octal (Base 8)
- Hexadecimal (Base 16)

The project accepts a number along with its original base and produces its equivalent representation in all four formats.

---

## 🚀 Features

- Convert numbers from any base between **2 and 36**
- Convert into:
  - Decimal
  - Binary
  - Octal
  - Hexadecimal
- Supports digits `0-9`
- Supports letters `A-Z` for bases greater than 10
- Simple and beginner-friendly
- Useful for learning number systems and base conversion
